# Agent Lab 协作约定

先阅读 `docs/HANDOFF.md` 与 `docs/BASELINE.md`，再判断实现和授权范围。

- 这是 Agent 基础脚手架，版本 0.1.0，固定基线标签 `scaffold-v0.1.0`。用户决定另开项目开发类似 Codex 的本地通用助手；新项目由用户自行创建。
- 用户已授权本次整理基线、修复验证脚本、同步文档，并提交和推送现有远程仓库。不要据此自动创建新项目或扩展文件、Shell 等应用工具。
- 默认教学方式仍是每次解释一个主要概念，用户亲自写代码和运行；明确委托执行时完成该次授权范围。保留现有手写实现，不替换成其他完整框架。
- 技术栈为 Python + LangChain + LangGraph + OpenAI API + PostgreSQL。图提供 chat/tools 循环，CLI 管理历史，数据库保存会话消息；当前不使用 checkpointer。
- 工具在 `src/agent_lab/tools.py` 的 `TOOLS` 中统一注册，模型与执行节点使用同一份列表。基线只保留乘法示例工具。
- 不读取、展示或复制真实 `.env`；密钥、数据库 URL、虚拟环境、聊天记录、数据库和日志不得进入 Git 或复用快照。`.env.example` 必须保持空值。
- 新应用必须使用独立 `.venv` 和本机配置，并优先使用独立数据库。不要让新项目的默认会话误接旧项目历史。
- 修改后优先使用项目 `.venv` 运行 `python -B scripts/verify_offline.py` 和 `pip check`。离线检查中的模型和数据库必须为替身，不请求真实模型或数据库。
- 真实模型与数据库验证由用户主动执行，或在明确授权后执行。进度必须区分源码存在、离线验证、模拟数据库验证、用户在线报告和协作助手真实在线验证。
- 定型后在本仓库维护基础功能、复用文档与必要修复；新应用能力在用户创建的新项目中推进。
