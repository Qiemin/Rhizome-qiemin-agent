## 复现

```powershell
.\.venv\Scripts\python.exe -B scripts/verify_offline.py
.\.venv\Scripts\python.exe -m pip check
```

基线的已测试环境为 Windows / Python 3.14.0。版本约束文件是该环境的运行时分发包快照，不是带文件哈希的跨平台依赖锁。

Git 标签固定代码和文档；标签对应的干净 ZIP 可用于复制新项目。后续如修改基线，应创建新的版本记录和标签，保留此标签的原始指向。
